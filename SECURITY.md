# Security policy

## Supported versions

Only the newest release of Annorex gets security fixes. If you use an older release, update to the newest release first.

## Report a vulnerability

Do not open a public issue for a security problem. Use the private reporting feature of GitHub instead.

1. Open the repository on GitHub and choose the Security tab.
2. Choose "Report a vulnerability".
3. Describe the problem and the steps that show it. Give the Annorex version, the Rex version, and the agent that you used.

The maintainer reads each report and replies through the same GitHub page. Annorex runs on your machine and opens no
network port. Reports about a flaw in Rex or in an agent belong to the project of that tool.
